# Project Canon

**Status: CANON**

This file is the protected entry point for explicitly accepted project principles.

## Important rule

Only explicitly accepted material belongs here. Agents must not infer new canon from implementation details, open questions, or their own proposals.

## Current state

The canonical corpus is being consolidated into this repository. Until a principle is explicitly entered here or in the linked canonical concept files, agents must classify it as `UNCERTAIN`, `DERIVED`, or `PROPOSAL` as appropriate.

## Protection

Changes to this file are conceptual changes and require explicit human approval.
