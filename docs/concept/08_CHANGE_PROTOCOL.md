# Change Protocol

**Status: CANON**

## Change classes

- C0: non-semantic documentation or formatting change.
- C1: local implementation change with bounded scope.
- C2: architectural change affecting boundaries, data flow, APIs, persistence, security, state, or core abstractions.
- C3: conceptual change affecting canon, axioms, ethics, terminology, or philosophical interpretation.

## Lifecycle

DRAFT, INVESTIGATION, PROPOSED, REVIEW, REVISION, VALIDATION, APPROVED, INTEGRATED.

Possible blocking states include REJECTED, BLOCKED, and SUPERSEDED.

C0 changes may be direct when semantic meaning is unchanged. C1 changes require appropriate tests. C2 changes require proposal and review. C3 changes require explicit human approval.
