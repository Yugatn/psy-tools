Конструктор колеса баланса

Выбирайте именно те характеристики жизни и развития, которые для вас важны. Используйте большой каталог, добавляйте собственные лучи, сравнивайте текущие оценки с желаемыми и возвращайтесь к своим результатам. Здесь нет универсального списка «правильных» сфер.

Мои колёса

Вы можете создавать несколько независимых колёс — например, для личной жизни, обучения или профессионального развития. Рекомендуется 6–16 лучей; технический максимум одного колеса — 48.

1. Выберите характеристики

Быстрый старт для пустого колеса.

Своя характеристика

Каталог не может охватить буквально все возможные характеристики. Любую собственную формулировку можно добавить отдельно. Ограничение 48 лучей действует только для читаемости одного колеса.

2. Мой результат

0 / 0оценено
—среднее / 10
—средний разрыв до цели

Бирюзовые сектора — текущие оценки. Оранжевые пунктирные границы — желаемый уровень. Неоценённый луч не равен нулю.

3. Сохраните прогресс

Данные хранятся только в этом браузере (localStorage). У других устройств нет автоматического доступа, но люди в том же профиле браузера могут увидеть ваши записи. Не вносите чувствительные персональные или медицинские сведения.

История прохождений

    Мои выбранные лучи 0

    Порядок лучей можно менять стрелками. Сначала выберите характеристику, затем оцените её текущее проявление и, при желании, установите цель. Пустое значение означает, что оценка пока не дана.

    Как интерпретировать колесо

    Это инструмент личной рефлексии, а не стандартизованный психометрический тест и не клиническая диагностика. Средняя оценка — условная арифметическая величина, зависящая от выбранных лучей. Не сравнивайте её с результатами других людей или разных наборов характеристик. Для отслеживания динамики лучше сохранять одинаковые лучи и одинаковый способ оценивания.

    История сохраняет состав лучей, оценки, желаемый уровень и заметки на момент снимка. При восстановлении снимка текущий состав колеса заменяется — предварительно сделайте резервную копию, если хотите сохранить прежнюю конфигурацию.
