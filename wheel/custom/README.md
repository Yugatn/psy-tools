# Конструктор колеса баланса · PSY-TOOLS

Публичная страница: https://yugatn.github.io/psy-tools/wheel/custom/

## Возможности

- Тематический каталог из **336 характеристик в 23 группах** с поиском, фильтрами и возможностью выбрать любой доступный луч.
- Собственные формулировки характеристик, которые не ограничены перечнем каталога.
- До 48 лучей на одном колесе (чтобы визуализация оставалась читаемой); до 24 разных колёс.
- Текущая оценка 0–10, желаемый уровень 0–10 или «Не оценено».
- Произвольный порядок лучей, заметки/маленькие шаги, SVG-колесо.
- Снимки прогресса (до 40 на колесо) с составом лучей, оценками, целями и заметками.
- Несколько сохранённых колёс; копирование, переименование, удаление, быстрый старт из 8 базовых сфер.
- Экспорт и импорт JSON, печать.
- Общее меню переключения на другие колёса: `wheel/wheel-nav.js`.

Каталог — **не исчерпывающее множество всех мыслимых характеристик**. Именно поэтому пользователь может создавать и выбирать собственные. 48 лучей на одном колесе — интерфейсный предел; при необходимости создавайте несколько тематических колёс.

## Данные и приватность

Ключ хранилища: `wheelBalanceCustomV1`; версия схемы: 1. Автоматической отправки на сервер нет. Пользователи в одном профиле браузера могут видеть общие локальные данные, защиты авторизацией пока нет. Не храните чувствительные сведения. При работе на общем устройстве используйте отдельный профиль браузера. JSON-файлы требуют безопасного хранения.

Конструктор предназначен для самооценки, не является стандартизованной психометрической или медицинской диагностикой. Средние показатели нельзя сравнивать между разными наборами лучей без оговорок.

## Автоматизированная проверка

Запуск из корня репозитория, требуется Node.js 18 или новее:

```bash
node wheel/custom/tests/smoke.cjs
node wheel/custom/tests/navigation.cjs
```

Проверяется: каталог и уникальные идентификаторы, пустое состояние, оценка/цель/среднее/разрыв, собственные характеристики, заметки, история и восстановление, копирование и изоляция нескольких колёс, быстрый старт, SVG, сброс, повторная загрузка, корректный и повреждённый JSON, нормализация некорректных значений, удаление колеса и всех данных.

GitHub Actions: `.github/workflows/custom-wheel-smoke.yml`. Он запускает проверки конструктора и корректности навигации между 19 страницами при изменениях в `wheel/**` или `LICENSE`.

Остаётся выполнить ручную проверку в реальном браузере на мобильном устройстве, клавиатуре и со скринридером; имитация DOM не заменяет такие проверки.
