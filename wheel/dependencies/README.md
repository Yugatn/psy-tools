## Назначение и методология

Инструмент для **добровольного самонаблюдения** частоты различных занятий, употребления продуктов и веществ. **Не** является тестом на зависимость, диагностикой, скринингом расстройств или рейтингом «полезности»/«вредности». Ежедневная музыка, мясо, работа, физическая активность и т.п. сами по себе не доказывают расстройство. Самооценки нельзя суммировать в «общий уровень зависимости».

### Уточнённая шкала частоты (редакция 2026-11-14)

Вопрос: **«Как часто это происходит сейчас или происходило обычно? Если занятие или употребление давно прекратилось, укажите статус воздержания».**

| Ответ | Пояснение |
|---|---|
| Несколько раз в день | Два и более эпизода в сутки |
| Ежедневно | Обычно один раз в день |
| Несколько раз в неделю | 2–6 раз в неделю, но не ежедневно |
| Каждую неделю | Около одного раза в неделю |
| Несколько раз в месяц | Обычно 2–3 раза в месяц |
| Раз в месяц | Около одного раза в месяц |
| Несколько раз в год | 2–11 раз в год |
| Раз в год | Около одного раза в год |
| Раз в несколько лет | Нерегулярно с многолетними промежутками |
| Не было последние месяцы | Был опыт, но перерыв длится менее 1 года |
| Не было 1–3 года | Опыт был, сейчас перерыв продолжительностью от 1 до 3 лет |
| Воздерживаюсь более трёх лет | Опыт был, воздержание продолжается более 3 лет |
| Не было такого опыта | Никогда в жизни |
| Не хочу отвечать | Явный отказ сообщать информацию |
| Не оценено | Вопрос пропущен; хранится `null` |

Для регулярных событий выбирайте типичную частоту за последние ~12 месяцев; для многолетних перерывов и редких событий используйте соответствующий статус или ретроспективный интервал. Это **смешанная порядковая шкала**, не равномерная шкала доз/часов/эпизодов. В SVG визуализируется условный **уровень частоты 0–9**, а не численное количество событий: многолетнее воздержание, недавний перерыв и отсутствие опыта имеют длину сектора 0, но **разные текстовые ответы**. «Не хочу отвечать» не равно «никогда» и не включается в статистику оцененных областей.

Три **отдельных необязательных** вопроса: трудности контроля, вытеснение значимых дел, продолжение несмотря на последствия. Они **не образуют диагностический критерий** и не дают выводов о расстройстве. Выбор «не хочу отвечать» касается частоты и **сам по себе не удаляет ранее сделанных заметок или ответов** — их удаление производится через очистку данных.

## Содержание и функциональность

- Каталог из 35 областей в 4 группах: сладкое, мясо, напитки, музыка, кино, телевидение, алкоголь, табак, никотин, каннабис, психоделики, другие вещества с ограниченным оборотом, игры, ставки, социальные сети, покупки, работа, спорт и др.
- 11 областей выбраны при первом открытии; можно добавить собственные, искать, фильтровать и удалить.
- До 36 лучей. Для каждого — отдельный текстовый ответ о частоте, три необязательных вопроса о самоконтроле и заметка.
- История снимков, восстановление текущих записей, экспорт/импорт JSON, удаление записей и печать.
- Навигация на другие колёса PSY-TOOLS.
- Локальное хранение без сервера и авторизации.

## Миграция прежней 30-дневной шкалы

Схема хранения **v2**, ключ остаётся `psyToolsHabitFrequencyV1` для совместимости с ранее созданной страницей. При первом открытии старой записи v1:

1. Выбранные области, собственные названия, вопросы о контроле и заметки сохраняются.
2. Старые баллы 0–6 по числу дней **не превращаются** в новые категории. Вместо этого сохраняются в `legacy30days` и показываются в карточке как прежняя 30-дневная шкала. Новую частоту нужно выбрать отдельно.
3. Старые снимки переходят в `archived30day`: хранятся как **архив без прямого сравнения с новой шкалой**, доступны в JSON и обозначаются в истории. Восстанавливать их как новые частоты нельзя.
4. Новые снимки записываются в `history` по схеме v2.
5. Экспорт JSON включает новую шкалу и прежний архив, если он был.

Если пользователь выбрал «не хочу отвечать», выбор сохраняется отдельным кодом `decline` без вывода о том, был ли опыт. История и ранее записанные заметки могут оставаться в экспортируемом архиве — для их полного удаления используйте «Удалить все данные».

## Приватность и безопасность

Хранилище — `localStorage` профиля браузера, без защиты от других пользователей этого же профиля, без синхронизации и регистрации. **Не вводите чувствительные, юридически идентифицирующие сведения**, медицинские подробности или данные третьих лиц. Для разделения нескольких людей используйте разные браузерные профили. JSON-файлы экспорта храните в безопасном месте. Изменение данных в другой вкладке блокирует запись со старой вкладки до перезагрузки.

При регулярном тяжёлом употреблении алкоголя резкое прекращение может приводить к опасному синдрому отмены — для изменения такого поведения обратитесь за медицинской помощью. Не прекращайте назначенные лекарства на основании этого колеса.

## Тестирование

Из корня репозитория:

```bash
node wheel/dependencies/tests/smoke.cjs
node wheel/custom/tests/navigation.cjs
```

Пройдено 50 проверок на имитации DOM и localStorage: 14 вариантов, отказ от ответа, отличие отсутствия опыта от нулевого балла, личные категории, история, импорт JSON, миграция v1 без ложного пересчёта, удаление, защита от перезаписи устаревшей вкладки. Настроен GitHub Actions workflow `.github/workflows/custom-wheel-smoke.yml`.

**Ещё не проверено на реальном устройстве:** VoiceOver/скринридеры, разные мобильные браузеры, скачивание файла и печать, внешний ответ GitHub Pages. Результаты модельных smoke-тестов не заменяют эти проверки.
