Коучинговый диалог через Telegram

Закрытый технический стенд интеграции. После вашего выбора передаётся только номер колеса, номер луча и необязательная оценка. По одному ответу на ход. Это не психотерапия и не диагностическая процедура. Внешняя генеративная ИИ-модель не используется.

Не для публичного использования.

Серверный API выключен по умолчанию и в production заблокирован. Для проверки нужен отдельный HTTPS staging-сервер и запуск внутри Telegram Mini App. Без них используйте офлайн-коуча.

Подключение Telegram SDK разрешается только на специально настроенном изолированном HTTPS-домене, не на общем GitHub Pages. По умолчанию запрещены все сетевые запросы. После отдельного ревью необходимо разрешить в CSP только конкретный адрес staging API. Сторонний скрипт всё равно может читать данные текущего домена, поэтому здесь не следует хранить чувствительные сведения до аудита.

1. Подключение Telegram

Мы используем только подписанные Telegram initData, проверяемые сервером. Данные аккаунта из JavaScript не считаются доказательством личности.

2. Выберите одну сферу

По умолчанию страница не читает результаты из localStorage. Вы вправе указать собственную оценку или не передавать балл вообще. Для удалённого пилота доступны только общие сферы; чувствительные тематические колёса не включены.

Данные с основного сайта GitHub Pages недоступны на отдельном домене Mini App. Если оценка сохранена в другом браузере или на другом сайте, укажите балл вручную либо оставьте поле пустым. Автоматического переноса нет.

3. Разговор

Ctrl+Enter / Cmd+Enter — отправить. Отмена удаляет серверную сессию, если соединение доступно; при сбое она истечёт автоматически.
