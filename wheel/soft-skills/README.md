# Колесо гибких навыков детей

Публичная страница: https://yugatn.github.io/psy-tools/wheel/soft-skills/

## Назначение

Независимый инструмент PSY-TOOLS для совместных наблюдений ребёнка, родителей и педагогов за применением гибких навыков. Не является диагностической методикой и не связан с академией Ukids официальным партнёрством.

## Направления

Основаны на открытой программе обучения Ukids (проверено 11 ноября 2026 года):

- **6 лет:** 4 сектора — эмпатия и эмоциональный интеллект, социальная адаптация, коммуникация, самоорганизация.
- **7–11 лет:** 12 секторов — самопрезентация, дружеские отношения, команда, целеполагание, самоорганизация, эмпатия, самооценка, договорённости, конфликты, критическое, финансовое и экологическое мышление.
- **11–12 лет:** 12 секторов — самопрезентация, построение отношений, команда, целеполагание, самоорганизация, эмпатия, самооценка, гибкость мышления, конфликты, критическое мышление, самоопределение, психологическая устойчивость.
- **12–16 лет:** 12 секторов — коммуникация, построение отношений, команда, целеполагание, самостоятельность, эмпатия, самооценка, гибкость мышления, конфликты, критическое мышление, самоопределение, психологическая устойчивость.

Официальный источник: https://ukids.ru/programm/ ; общая информация: https://ukids.ru/

Оценочные вопросы, поведенческие примеры, упражнения, шкала 0–10 и алгоритм отображения — самостоятельная разработка, **не тест и не возрастные нормы Ukids**. Отсутствующая оценка отличается от нуля.

## Функции

- Динамическое SVG-колесо 4/12 секторов, адаптивное отображение.
- Дискретная оценка 0–10, отдельный статус «Не оценено».
- Объяснение навыка, пример, упражнение и вопрос для беседы.
- Роли наблюдателя: вместе с ребёнком, взрослый, ребёнок.
- Раздельные оценки, заметки и история для **анонимного локального профиля ребёнка + возрастной программы + роли** (до 8 профилей, без аутентификации).
- Явное сохранение снимка **вместе с заметкой**, восстановление старых оценок и заметок, экспорт/импорт JSON, печать.
- Среднее по оценённым лучам и изменение к последнему снимку по сопоставимым лучам.
- Удобные для касания кнопки оценки и восстановление фокуса клавиатуры после обновления.
- Сохранение в localStorage под ключом `psyToolsSoftSkillsV1`, с сохранением обратной совместимости с данными первоначальной версии. **Выбранный локальный профиль также восстанавливается после перезагрузки**; это не аутентификация.

## Приватность и ограничения

**Нет серверного аккаунта, сетевой отправки результатов и аутентификации.** Другие устройства не видят локальные данные, однако другой человек **в том же профиле браузера** может их прочитать. Поэтому не вводите ФИО и другую идентифицирующую информацию о ребёнке. Локальные анонимные профили в приложении разделяют оценки, но не ограничивают доступ — **для действительной приватности разных детей используйте разные профили браузера**; перед передачей устройства очищайте данные. Очистка только этого модуля не затрагивает другие колёса.

Данные не являются конфиденциальными на общем устройстве; для чувствительных детских данных потребуется аутентификация и шифрование.

## Автоматизированная регрессионная проверка

Запуск из корня репозитория (Node.js 18+):

```bash
node wheel/soft-skills/tests/smoke.cjs
```

Набор из 27 smoke-проверок на имитации DOM и localStorage: возрастные программы, сохранение оценок, средние баллы, сохранение фокуса, заметки и история, сравнение снимков, локальные профили, восстановление выбранного неосновного профиля после перезагрузки, смена возраста, повторная загрузка, миграция v1, удаление записей, восстановление из JSON и обработка повреждённого импорта.

GitHub Actions workflow: `.github/workflows/soft-skills-smoke.yml`. Запуск настроен при изменениях `wheel/soft-skills/**`, но успешное выполнение в GitHub Actions необходимо подтверждать отдельно.

**Ограничения тестов:** имитация DOM не заменяет ручную проверку реального браузера, VoiceOver, скринридеров, мобильных устройств, браузерного экспорта и печати.
