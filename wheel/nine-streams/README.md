# Кубическая матрица девяти потоков восприятия (КДИ-9 / PSY-TOOLS)

**Исследовательский модуль, версия данных 1.** Автор философской модели девяти потоков — Югатн. Модуль разработан как самостоятельная статическая HTML-страница с локальным сохранением, без внешних библиотек и серверной синхронизации.

## Что реализовано

- SVG-проекция **27 интерактивных ячеек** по трём осям: тип организма (человек, пещерная рыба, летучая мышь) × среда (привычная, темнота, вода) × срез наблюдения (1–3). Эта сетка — **пилотный иллюстративный набор категорий**, не полный перечень организмов или миров.
- В каждой ячейке девять исходных потоков АС: **зрение, слух, обоняние, вкус, осязание, проприоцепция, равновесие, интероцепция, социальная сопричастность** (последний — авторское социально-аффективное измерение, не доказанный отдельный рецептор).
- Каждый поток имеет взаимоисключающие статусы **неизвестно / наблюдается / не обнаружено / неприменимо**. **UNKNOWN ≠ ABSENT**, **не оценено ≠ 0**. Без доказательств все поля изначально неизвестны.
- Только для режима **человека (самонаблюдение)** доступна добровольная оценка субъективного комфорта от 0 до 10; оценки других видов заблокированы, так как чужой субъективный опыт нельзя приписать измерением.
- Колесо из девяти отдельных радиальных лучей не соединяет пропуски в замкнутый многоугольник и не превращает «неизвестно» в нулевой балл.
- Место для свободной заметки и источника наблюдения с ограничением длины; метка времени изменения.
- Локальное сохранение, экспорт, импорт JSON, удаление одной ячейки или данных всего модуля. Импорт ограничен 2 МБ, принимает только собственную версионируемую схему, удаляет нераспознанные координаты, нормализует диапазоны и требует подтверждение замены текущих данных.
- Адаптивная компоновка для мобильного устройства, управление кубом мышью/касанием/клавиатурой, SVG и текстовые альтернативы.

## Данные, приватность и безопасность

Вся логика выполняется на устройстве; сетевые запросы интерфейс не отправляет. Состояние хранится под ключом `psy-tools.nine-streams.v1` в localStorage этого браузерного профиля, **не зашифровано**. Данные не интегрируются автоматически в личный кабинет остальных колёс, не синхронизируются между браузерами или пользователями. Любой с доступом к тому же профилю браузера потенциально может прочитать записи. При отключённых cookies/хранилище экспорт остаётся полезным как резервная копия.

Импорт содержит только формат приложения; никакое содержимое личных заметок не интерпретируется как HTML. Тексты вставляются как `textContent` / значение элемента, а не через `innerHTML`. Используется стандартная безопасная обработка JSON. Не размещайте в заметках чужие персональные данные без согласия. Приложение не предназначено для клинической диагностики или заключений об органах чувств; при объективных нарушениях нужна независимая медицинская оценка.

## Ограничения и дальнейшее развитие

- 27 ячеек и три варианта каждой оси — UX-прототип. Для сравнительной биологии нужны расширяемые справочники видов, сред, дат и отдельное поле дополнительных модальностей (например, электрорецепции или магниторецепции). Нельзя выдавать человеческую девятку за исчерпывающую таксономию всех животных.
- «Срез 1–3» обозначает произвольные точки сравнения; это **не** установленные этапы эволюционной истории.
- Код не отображает доказанные переходы между физическими мирами и не рассчитывает «энергетическую ценность» субъектов.
- Девятый поток — социальная сопричастность, не догадка о мыслях других или индикатор социальной успешности.
- В будущей итерации полезны: редактируемые оси с более строгими типами данных, привязка к реальным датам, история изменений отдельной ячейки, внешние доказательства с полной атрибуцией, синхронизация кабинета только по отдельному согласию, тесты UI на мобильных браузерах, доступная таблица вместо куба.
- Прежде чем объявлять инструмент «тестом» или диагностикой, нужна независимая методологическая проверка.
