# AI Work Area

This directory stores auditable artifacts for AI-assisted development.

## Proposal structure

`.ai-work/proposals/PROP-0001/` may contain `manifest.yaml`, `task.md`, `source-analysis.md`, `proposal.md`, `evidence.md`, `review.md`, `canon-audit.md`, `architecture-audit.md`, `verification.md`, `revisions/`, and `final-report.md`.

The proposal directory is process evidence, not a substitute for Git history.

## Status rule

A proposal is not integration-ready merely because an AI agent says it is correct. Evidence, tests, review, and the required approval gate must be recorded.
