# Квадрат Пифагора — Telegram Mini App / браузер

Самостоятельный клиентский калькулятор нумерологической психоматрицы для проекта PSY-TOOLS. **Не психодиагностический инструмент.** Авторское направление PSY-TOOLS — Югатн. Ссылка на само приложение на GitHub Pages:

**https://yugatn.github.io/psy-tools/mini-apps/pythagoras/**

Исходники:
- [index.html](./index.html) — адаптивный интерфейс, подробное отображение матрицы и интеграция с Telegram WebApp API.
- [calculator.js](./calculator.js) — детерминированное расчётное ядро без сторонних зависимостей.
- [тесты](../../tests/pythagoras-mini-app.test.cjs) — контроль формул и календаря.
- [CI](../../.github/workflows/pythagoras-mini-app.yml).

## Возможности

1. Ввод даты рождения (с проверкой календаря, включая 29 февраля).
2. Расчёт четырёх рабочих чисел.
3. Психоматрица 3×3 в расположении **1–4–7 / 2–5–8 / 3–6–9**.
4. Подсчёт восьми традиционных линий: три строки, три столбца, две диагонали.
5. Прозрачное объяснение арифметики, видимые повторы 1–9 и нейтральные описания символических тем.
6. Переключение между вариантами **первой значимой цифры дня** и **буквальной первой цифры записи даты**: для `03` это 3 или 0 соответственно.
7. Копирование текстового результата, системное меню «Поделиться», печать / PDF браузера.
8. Работа в Telegram WebView и обычном мобильном браузере без серверной части. Никакой регистрации, передачи Telegram User ID или записи дат рождения на сервер.

## Алгоритм

Для даты DD.MM.YYYY записываются восемь цифр `DDMMYYYY` (нули сохраняются в представлении даты).

- **Р1** — сумма цифр восьмизначной даты.
- **Р2** — сумма цифр Р1, один шаг (например 29 → 11, **не** 2).
- **Р3** = Р1 − 2 × первая цифра дня; выбранный вариант для дней 01–09 указан прямо в интерфейсе.
- **Р4** — сумма цифр Р3.

Все цифры даты и четырёх рабочих чисел (без нулей и знака минус) считаются в ячейках 1–9. **Вариант с дополнительным +19 для рождённых после 2000 не используется**, поскольку это иной алгоритм из отдельных школ; эту разницу нельзя скрывать.

Проверочный пример: **14.03.1992 → 29 / 11 / 27 / 9**, количества цифр: 1→4, 2→3, 3→1, 4→1, 5→0, 6→0, 7→1, 8→0, 9→4.

**Важно:** нет научных данных, подтверждающих возможность предсказать по дате рождения характер, уровень интеллекта, состояние здоровья, успешность или судьбу. Названия «Здоровье», «Удача», «Характер», «Память» используются как исторические названия ячеек нумерологической схемы, а не диагнозы.

## Как подключить к Telegram

Mini App — это HTTPS-страница, которую бот Telegram может открыть во встроенном WebView. Исходники уже организованы как веб-клиент. **Для активации Mini App у собственного бота требуется самостоятельная настройка через [@BotFather](https://t.me/BotFather)**; без бота Telegram-адрес `t.me/<имя_бота>/...` не создан и его нельзя придумывать.

1. В Telegram откройте @BotFather и создайте бота через `/newbot`, если его ещё нет. Никому не сообщайте токен бота и не добавляйте его в браузерный JS или публичный GitHub.
2. Для нового бота настройте **Main Mini App** (пункт **Bot Settings → Configure Mini App** или соответствующая команда BotFather, название меню может измениться).
3. Укажите HTTPS URL: `https://yugatn.github.io/psy-tools/mini-apps/pythagoras/`.
4. Укажите краткое название и иконку при необходимости; затем откройте приложение из профиля бота / специальной ссылки, которую предоставит BotFather.
5. Протестируйте на iOS и Android внутри Telegram. Приложение вызывает `ready()` и `expand()`, когда Telegram передаёт параметры WebApp. При открытии обычным браузером SDK не подгружается.

[Официальная документация Telegram Mini Apps](https://core.telegram.org/bots/webapps).

## Приватность и ограничения

- Дата не сохраняется ни в localStorage, ни в cookies, ни в базе данных; при закрытии страницы расчёт исчезает.
- Telegram WebApp SDK подгружается с `telegram.org` только при обнаружении признаков открытия внутри Telegram. Код не отправляет данные рождения на сервер.
- Системный «Поделиться» и «Скопировать» передают дату рождения **только по явному действию пользователя**; нельзя публиковать данные другого человека без согласия.
- Нет бэкенда, идентификации пользователя, платежей и обработки токенов.
- Встроенный калькулятор принимает ISO `YYYY-MM-DD` и текстовый `DD.MM.YYYY` (для программного вызова); в UI используется системный календарный ввод.
- Не применяется к медицинским, юридическим, кадровым или психологическим решениям; традиционная схема не является научной диагностикой.

## Проверка и разработка

```bash
node --test tests/pythagoras-mini-app.test.cjs
node --check mini-apps/pythagoras/calculator.js
```

Для локального запуска откройте `mini-apps/pythagoras/index.html` в браузере или используйте простой статический HTTP-сервер. Проверки UI внутри Telegram и фактическую публичную доступность Pages выполняют отдельно; успешный commit не подтверждает публикацию у Telegram-бота.
