# PSY-TOOLS

Экосистема инструментов для самонаблюдения, профориентации, психодиагностических исследований и работы с персональными моделями развития.

## Основные направления

- **Колёса баланса** — оценка сфер жизни и рекурсивная детализация каждого луча.
- **Активность и здоровье** — питание, сон, отдых, движение, самочувствие, отношения, развитие и другие связанные области.
- **Трудовая деятельность и профессиональные отношения** — работа, доход, руководство, коллеги, время, нагрузка, развитие и карьерные перспективы.
- **Мобильное приложение** — единый Flutter-интерфейс для колёс, конструктора, дневника, истории, резервного копирования и будущей аналитики.
- **PSY-TOOLS web** — текущие веб-прототипы и публичные инструменты.

## Веб-конструктор

[Создать собственное колесо](https://yugatn.github.io/psy-tools/wheel/custom/) · [Каталог всех колёс](https://yugatn.github.io/psy-tools/wheel/hub.html)

Конструктор позволяет выбирать характеристики из расширяемого тематического каталога, добавлять свои лучи, выставлять текущий и желаемый уровень, сохранять историю и экспортировать данные. Локальное хранение не обеспечивает изоляцию между пользователями одного профиля браузера.

## Mobile

Мобильная разработка находится в [mobile_app](./mobile_app/).

Ключевые принципы:

1. local-first: базовые функции работают без сети;
2. пользователь контролирует свои данные;
3. колёса образуют рекурсивный граф;
4. дневник может связываться с колесом и отдельным лучом;
5. данные имеют версионируемую схему и проходят миграцию и проверку при импорте;
6. тестирование и форматирование выполняются через GitHub Actions.

Подробнее: [mobile_app/ARCHITECTURE.md](./mobile_app/ARCHITECTURE.md).

## Концепция колеса

Любой луч может быть самостоятельной областью исследования. Поэтому система не ограничивается одним уровнем:

**Колесо → луч → подробное колесо → луч → следующая детализация.**

Глубина не задаётся заранее.

## Дневник

Дневник является частью системы рефлексии, а не отдельным блокнотом. В текущей версии предусмотрены вопросы:

> Вы можете вспомнить моменты, которые вызывают у Вас чувство радости, внутреннего спокойствия, счастья?

> Что делает Вас счастливым?

В дальнейшем записи будут связываться с оценками, лучами, целями и динамикой.
