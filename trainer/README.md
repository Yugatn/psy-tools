# Adaptive Skill Trainer · Тренажёр гибких навыков

**Автор:** Югатн (Yugatn), 2026. Часть [PSY-TOOLS](../README.md).

**Публичная страница после слияния в main:** https://yugatn.github.io/psy-tools/trainer/

## Первая рабочая версия

- Четыре программы: **5–7, 8–11, 12–17 и 18+ лет**; маленькие дети выполняют задания вместе со взрослым.
- **16 оригинальных жизненных ситуаций**, 8 направлений: эмоциональная саморегуляция, эмпатия, общение, границы и согласие, сотрудничество, критическое мышление, планирование, конфликты.
- Каждый сценарий: **цель → выбор действия → разбор → коучинговые вопросы → реальная практика → наблюдаемые критерии → рефлексия**.
- Прозрачное правило рекомендаций: сначала неразобранная ситуация, затем разобранная без отмеченной практики. Это не ИИ-диагностика.
- Прогресс основан только на **самоотчёте об участии**, необязательная субъективная уверенность до/после. Не следует приравнивать его к уровню способности.
- По умолчанию история только в памяти вкладки. При явном согласии — localStorage текущего профиля браузера. Экспорт и валидация импорта JSON, удаление. Нет аккаунта, аналитики и сетевой передачи данных.

## Ограничения и приватность

Это образовательный прототип, не клинический инструмент или стандартизированный тест. Возрастные диапазоны ориентировочны; особенности развития, язык, инвалидность, культура и обстановка могут менять доступность. Варианты служат для исследования последствий, не оценки достоинства субъекта. Нельзя делать вывод об освоении навыка только по одному ответу.

**localStorage не обеспечивает изоляции разных пользователей одного профиля браузера.** Для разных детей используйте разные браузерные профили или временную сессию. Не записывайте имена, медицинские сведения и другие чувствительные данные. Экспортированный JSON может содержать личные рефлексии.

Методологические ориентиры для последующего изучения: [CASEL](https://casel.org/fundamentals-of-sel/), [OECD](https://www.oecd.org/en/topics/social-and-emotional-skills.html). Эти общие модели не валидируют наши 16 авторских упражнений.

## Проверка

В корне проекта выполните:

    node --check trainer/data.js
    node --check trainer/core.js
    node --check trainer/app.js
    node --test trainer/test.cjs

CI: [.github/workflows/adaptive-skill-trainer.yml](../.github/workflows/adaptive-skill-trainer.yml). Приложение статическое, без внешних библиотек: входная страница — [trainer/index.html](./index.html).

## Дорожная карта

1. Добровольное возрастно-ориентированное тестирование ясности упражнений и безопасности.
2. Расширить возрастную модель: 0–12 месяцев, 1–3, 3–5, 6–9, 10–12, 13–17 и взрослые. Для раннего возраста — совместные игры/наблюдения, а не самостоятельные экранные ответы.
3. Сверить с существующим Notion-каталогом **368 навыков (в том числе 152 soft skills)**. В текущую версию он **не импортирован**.
4. Связать с [картой навыков](../skills/) и [детским колесом](../wheel/soft-skills/), не смешивая несопоставимые оценки.
5. Отдельно проверить доступность, мобильные устройства, конфиденциальность при работе нескольких пользователей, влияние практики в жизни.
6. После проверки безопасности можно спроектировать необязательного ИИ-коуча и экспорт в пособие.
