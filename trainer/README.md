# Adaptive Skill Trainer · Тренажёр гибких навыков

**Автор:** Югатн (Yugatn), 2026. Часть [PSY-TOOLS](../README.md).

**Публичная страница после слияния в main:** https://yugatn.github.io/psy-tools/trainer/

## Первая рабочая версия

- Четыре программы: **4–6, 7–11, 12–17 и 18+ лет**; маленькие дети выполняют задания вместе со взрослым.
- **16 оригинальных жизненных ситуаций**, 8 направлений: эмоциональная саморегуляция, эмпатия, общение, границы и согласие, сотрудничество, критическое мышление, планирование, конфликты.
- Каждый сценарий: **цель → выбор действия → разбор → коучинговые вопросы → реальная практика → наблюдаемые критерии → рефлексия**.
- Прозрачное правило рекомендаций: сначала неразобранная ситуация, затем разобранная без отмеченной практики. Это не ИИ-диагностика.
- Прогресс показывает три раздельных **состояния деятельности**: «не начато», «в процессе» и «закреплено» по самоотчёту. Последнее выставляется лишь после **двух отметок всех наблюдаемых критериев в разные дни с интервалом от 3 дней**. Повтор в тот же день заменяет предыдущую отметку. Доступны отмена записи и необязательная субъективная уверенность до/после. Это не доказательство переноса навыка, уровня способности или педагогическое заключение.
- По умолчанию история только в памяти вкладки. При явном согласии — localStorage текущего профиля браузера. Экспорт JSON v2 (с рефлексиями и журналом практики), импорт v1/v2 с сохранением прежних ответов и удаление. Нет аккаунта, аналитики и сетевой передачи данных.

## Редакционная проверка и происхождение

Все существующие 16 упражнений маркируются как **«на проверке»** (редакционное состояние) и **«не подтверждено»** (научно-методическая валидация). «Согласовано» может появиться только после отдельного подтверждения автором; автоматическое прохождение тестов не означает согласования. Одобренные тексты не перезаписываются при развитии тренажёра.

Сверка с [основным пособием Notion](https://app.notion.com/p/412d132385998128a5abdc0f38a911c3) показала **95 тематических единиц (35 первоначальных + 60 новых)**, а не 95 законченных глав. Внутрь приложения не переносился авторский текст Notion: текущие 16 заданий — отдельный пилотный материал. Четыре возрастные программы приведены к диапазонам пособия (4–6, 7–11, 12–17, 18+), при этом старые результаты привязаны к стабильным ID сценариев и не теряются.

## Ограничения и приватность

Это образовательный прототип, не клинический инструмент или стандартизированный тест. Возрастные диапазоны ориентировочны; особенности развития, язык, инвалидность, культура и обстановка могут менять доступность. Варианты служат для исследования последствий, не оценки достоинства субъекта. Нельзя делать вывод об освоении навыка только по одному ответу.

**localStorage не обеспечивает изоляции разных пользователей одного профиля браузера.** Для разных детей используйте разные браузерные профили или временную сессию. Не записывайте имена, медицинские сведения и другие чувствительные данные. Экспортированный JSON может содержать личные рефлексии.

Методологические ориентиры для последующего изучения: [CASEL](https://casel.org/fundamentals-of-sel/), [OECD](https://www.oecd.org/en/topics/social-and-emotional-skills.html). Эти общие модели не валидируют наши 16 авторских упражнений.

## Дорожная карта

1. Добровольное возрастно-ориентированное тестирование ясности упражнений и безопасности.
2. Расширить возрастную модель: 0–12 месяцев, 1–3, 3–5, 6–9, 10–12, 13–17 и взрослые. Для раннего возраста — совместные игры/наблюдения, а не самостоятельные экранные ответы.
3. Постепенно включить **95 тематических единиц** рабочего учебника Notion после проверки дублирования и редакционного согласования; не представлять их как готовые главы. Текущие 16 пилотных сценариев не выдавать за утверждённые главы.
4. Связать с [картой навыков](../skills/) и [детским колесом](../wheel/soft-skills/), не смешивая несопоставимые оценки.
5. Отдельно проверить доступность, мобильные устройства, конфиденциальность при работе нескольких пользователей и **перенос навыков в жизнь**. Маршрутизация по интервалам — инженерная гипотеза, не доказанная оптимальная образовательная периодичность.
6. После проверки безопасности можно спроектировать необязательного ИИ-коуча и экспорт в пособие.
