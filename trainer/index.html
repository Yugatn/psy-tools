Мои данные

По умолчанию тренировка работает без постоянного сохранения. Сервер не используется, аккаунтов нет. Не вводите настоящие имена детей, медицинские сведения или другие чувствительные данные.

Один профиль браузера не защищает данные от других людей, пользующихся этим же профилем. Для разных участников используйте разные профили браузера. JSON может содержать личные заметки.
